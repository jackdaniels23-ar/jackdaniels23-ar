## v1.0.0 - 2026.07

Initial stable release.

- Added generated Shadow Terminal README workflow.
- Added ASCII portrait terminal banner.
- Added Matrix theme assets.
- Added GitHub stats, streak, trophies, visitors, activity graph, and snake animation.
- Added boot animation, rotating quote SVG, badges SVG, and Shadow Linux branding.
- Added profile data source in `generator/config/profile.json`.
- Added CI workflow for generator builds.
- Added release versioning in the generated banner and README.
